🔑 Connexion GitHub

Connexion GitHub

Nécessaire pour que ce dashboard puisse modifier config.json et relancer le workflow à ta place. Ces informations restent uniquement dans ce navigateur (localStorage), jamais envoyées ailleurs qu'à api.github.com.

Crée-le sur github.com → Settings → Developer settings → Fine-grained tokens → limité à ce dépôt, permissions "Contents: Read and write" + "Actions: Read and write".
